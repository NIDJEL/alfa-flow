# Продуктовая логика

ALFA FLOW — демонстрационный, не официальный банковский продукт.

Предприниматель хочет понять безопасную сумму, не вводить известные банку сведения повторно,
отправить заявку и видеть следующий шаг. Аналитик хочет получить единый пакет фактов,
причин решения и истории общения вместо разрозненных документов.

Путь клиента: обзор → цель/продукт → параметры → предзаполненные данные и документы →
проверка → предложение или уточнение → принятие → имитация подписания и выдачи.

Путь банка: очередь → проверенные синтетические источники → причины/снимок →
запрос уточнения либо мотивированное решение → аудит и replay.

Сначала P0 (состояние, роли, финансовая математика и выдача), затем три полезных отличия:
Financial Twin Lite, What-if и воспроизводимый паспорт решения. AI/OCR не критический путь.
Интервью и реальные банковские исследования не проводились; гипотезы не выдаются за результаты.
